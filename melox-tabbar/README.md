# MeloX TabBar

独立 Compose 组件，直接提取 MeloX 的底部 chrome、三层玻璃、水珠拖动、搜索按钮、收缩动画和动态明暗采样。未替换本项目已有底栏。

公开入口：`com.lladlam.melox.ui.MeloXTabBar`、`MeloXTabBarScaffold`。

接入、参数、来源、差异与字体授权边界见 [组件文档](../docs/melox-tabbar.md)。原文件与提取文件 SHA-256 见 [清单](../docs/melox-tabbar-extracted/manifest.json)。独立演示在 `melox-tabbar-demo`。
