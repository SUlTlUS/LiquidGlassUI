# Slider 静止态阴影（1.0.10）

## 1.0.11 端点定位修复

原公式将把手左边界允许范围设为 `-thumbWidth/4 .. trackWidth-thumbWidth*3/4`，导致 40dp 把手在两端各伸出 10dp。现改为 `0 .. trackWidth-thumbWidth`，中间位置仍以轨道上的数值位置为把手中心；RTL 从右对齐起点反向平移。弹簧进度超调也不能越过这两个定位边界。

只限制把手静止尺寸的水平定位，不改变按压放大、速度形变、折射、阴影或触摸数值映射。按压放大过程中及阴影本身仍可向外延伸，这是与静止把手实体越界不同的效果。

新增 `LiquidSliderPositionTest`，覆盖 0% / 50% / 100%、RTL、不同轨道宽度及进度超调。原始提取快照不变，活动文件哈希已更新到本次授权修改。

用户明确授权修改组件后，本次只改 `catalog/components/LiquidSlider.kt`。它不再与原提取逐字节一致，变更哈希以 user-authorized-local-change 类型记入合并清单；原始提取文件未改。

静止态参照本地 `Untitled.fig` 的 `1:38 Knob` 两个可见 DROP_SHADOW：

- 扩散层：黑色 12%，半径 13dp，向下偏移 6dp。
- 贴近滑块的阴影层：黑色 12%，半径 4dp，向下偏移 0.5dp。

按压进度从 0 到 1 时，扩散层淡出，近层透明度从 12% 渐变为原来的 5%，偏移渐变到原来的 4/6dp；按住状态与原有阴影参数一致，释放沿现有动画回到双层阴影。进度限制在 0..1，避免弹簧超调产生非法透明度。

复用原 ShadowElement 渲染器，没有改全局 Shadow 默认值。其他按钮、开关、底栏、滑块折射/模糊/高光、尺寸、触摸和回调均未修改。Android 阴影渲染与 Figma 的模糊实现可能不同，参数对应不等于像素完全一致。

新增三个单元测试覆盖静止参数、按住参数、超调与中间透明度。真机仍需验证：浅色底的静止阴影、按住/松手过渡、左右拖动及端点处是否被容器裁切。
