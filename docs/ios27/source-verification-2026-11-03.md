# FlClash 机制补齐：用户验证清单

约定：保留 Sketch 采样、模糊、折射与材质；对齐 FlClash 的几何、交互、路由、图标、布局和主题角色。视觉效果由用户验收。以下方框均留给真机验证，不因单元测试通过而预先勾选。

入口：主页 `•••` → **完整机制验证**。返回主页可继续测试原多级菜单与 Goo。验证页的“深色 / 纯黑 / RTL / 大字”和种子色按钮只影响该页，不修改手机设置。

以下均在浅色、深色下与 FlClash 对照；采样与光学材质仍为 Sketch。

- [ ] 底栏透镜：左右两端也有原版的细暗线，拖动和回落过程中没有突然变粗。

- [ ] 菜单、二级/三级卡片、通用 Popup 和弹窗：对照角部亮度与向内渐弱的光环，外侧暗线没有挤进玻璃内部。

## 2. 底栏

- [ ] 点击四个标签，选中状态正确；拖动跨多个标签、快速甩动和反向，松手落在预期目标。
- [ ] 透镜抬升、拉伸、制动压缩、落下，以及手指光晕的扩散/消退符合预期。
- [ ] 在底栏外围约 8dp 以内点击仍可选中；更远的点击不触发。
- [ ] 长标签先统一缩小，达到最小字号后才省略；鼠标悬停可读到完整提示。
- [ ] 鼠标移入、点击并保持不动、移出：悬停高亮和透镜偏移正确恢复；右键不选中。
- [ ] RTL 下图标顺序、拖动方向、选中与文字一致。
- [ ] Tab/方向键移到标签时有焦点标记，Enter/空格激活；TalkBack 读出完整标签与选中状态。

## 3. 弹窗

- [ ] “普通”：入场由 1.2 倍收至正常；退出保持当前比例淡出。入场中立即关闭也不跳变。
- [ ] 按住卡片内部只放大；拖出边缘才产生有限拉伸；子按钮、滚动和输入仍可操作。
- [ ] “输入框”：标题居中，尾部图标不挤偏标题；键盘显示/隐藏时弹窗避让，输入内容保留。
- [ ] “长按钮”：不足以并排时改成竖排，取消置底；大字/横屏下文字没有裁切。
- [ ] “三项/危险”：三个操作竖排、取消置底、删除使用危险色；各按钮执行对应操作。
- [ ] “长内容”：正文可滚动，操作区可达；点击正文不会误关，点击外部或系统返回能关闭。
- [ ] 连续快速点确定不会执行多次；关闭动画期间按钮不可再次触发。

## 4. 通用 Popup

- [ ] “任意内容 Popup”：从源控件展开；关闭后返回源控件，前景不重复、玻璃不叠加。
- [ ] 输入内容后“返回结果”，页面显示对应字符串；取消返回空值。
- [ ] “等待返回值”：关闭动画结束后才显示“协程返回”，不会在回收途中改变源页面。
- [ ] 关闭“回源”：退出采用原位缩小与淡出；不出现飞回源控件的水滴。
- [ ] 模态开启：点击外部只关闭 Popup，背景计数不增加，焦点不会跑到背景。
- [ ] 模态关闭：点击“背景计数 +1”，Popup 关闭且计数增加一次；页面焦点保留。
- [ ] Popup 内点击“移动源锚点”，定位随源变化；“改变内容高度”时尽量固定右上角。
- [ ] 在 Popup 输入框打开键盘，以及旋转/改变窗口大小后，内容留在安全区；空间不足时可以操作关闭。
- [ ] 回源结束后源控件恢复显示和焦点，下一次还能正常打开。

## 本轮实现接口

- `GlassDialog`：内容/标题尾部插槽、任意动作、输入框模式、自适应按钮、关闭回调。
- `GlassPopupState<T>` / `show()` / `dismiss(result)`：结果在关闭动画完成后交付。
- `GlassPopupBox` / `GlassPopupSourceContent` / `GlassPopupAnchor` / `GlassPopup`：任意源内容、前景快照、锚点跟踪与通用 Popup。
- `GlassPopupProperties`：模态、焦点、外部点击/返回关闭、浮层主题与回源策略。
- `GlassTheme` / `GlassColorStyle`：主题种子与纯黑角色；不替换 Sketch 光学。
- `GlassGlyphs`：124 个参考静态图标、两个动态图标、平台返回图标选择；生成器可用 `python tools/generate_glass_glyphs.py --check` 核对。

构建和自动测试结果以 `plan.md` 最新记录为准。本清单不代表用户已经验收通过。
